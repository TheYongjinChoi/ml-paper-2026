# 제3장 R 분석 스크립트 안내

## 실행 순서

RStudio에서 아래 파일을 순서대로 실행합니다. 각 파일은 `01_package.R`을 자동으로 불러오므로 RStudio의 작업 폴더를 별도로 지정하지 않아도 됩니다. 결과 표와 그림은 `code/results/`에 저장됩니다.

1. `01_package.R` — 패키지 확인, CSV 읽기, 결과변수와 선행 설명변수 구성
2. `02_descriptive_analysis.R` — 결측, 분기별 매출 변화와 순진입률, 조직·지원 상태 분포
3. `03_CRE.R` — 시장·분기 고정효과와 Mundlak 방식의 상관임의효과
4. `04_Random_Forest_classification.R` — 두 경제지표의 방향을 조합한 네 유형의 연도별 분류
5. `05_Random_Forest_regression.R` — 매출 변화와 순진입률의 연도별 예측
6. `06_robustness.R` — 결과변수 대체 산식, 개업·폐업 분해, 조직 확인 표본 비교
7. `07_adjusted_model.R` — 이전 지원 이력을 추가한 조정 모형과 조직·지원 비교 가능성 점검
8. `08_visualization.R` — 경제지표 추세, 지원 상태, 예측변수 중요도 그림

R 4.6.1에서 실제 `panel_data_21-25.csv`로 실행 확인했습니다. `read.csv()`는 현재 Windows의 문자 인코딩 설정에서 한글 값을 제대로 읽지 못했으므로 모든 스크립트는 `readr::read_csv(..., locale = readr::locale(encoding = "UTF-8"))`를 사용합니다. 첫 실행에서 패키지가 없다고 나오면 오류 메시지에 표시된 이름을 `install.packages()`로 설치합니다.

## 변수와 분석 범위

- 매출 변화: 전년 동기 로그 매출 차이 × 100. 2021년 이전 매출이 현재 패널에 없어 2022년부터 계산됩니다. 매출 원천 열의 정확한 집계기간은 자료 정의서와 최종 대조해야 합니다.
- 순진입률: `(당기 개업 - 당기 폐업) / 전분기 점포 수 × 100`.
- 시장 특성: 매출 변화에는 결과기간 시작 시점인 4분기 전 값, 순진입률에는 전분기 값을 사용합니다. 지원중 여부는 연도 단위이므로 두 결과 모두 전년 동기 상태를 사용합니다.
- 업종 다양성: `stores_by_industry_cs...` 점포 수로 계산한 Shannon 엔트로피. 업종 코드와 점포 합계의 원자료 정의를 확인해야 최종 변수로 확정할 수 있습니다.
- 2020년 상인조직 유무: 133개 시장에서 미확인입니다. FE 모형에는 시간불변 단독항을 넣을 수 없고, CRE 표본은 확인된 시장으로 제한됩니다.
- 지원사업: `support_active_0_1`의 0은 연구에 사용한 공개 파일에서 해당 연도 지원기간이 확인되지 않았다는 뜻입니다. 지원사업 선정과 경제적 결과의 인과관계는 이 스크립트로 확인할 수 없습니다.

## 랜덤포레스트의 해석

연도별로 1·2분기는 학습, 3분기는 검증, 4분기는 최종 평가에 사용합니다. 이는 **연도별 탐색 비교**이며, 한 해의 앞선 두 분기만 학습하므로 평가값과 중요도가 불안정할 수 있습니다. 각 연도·결과별로 단순 기준모형과 같은 평가 표본에서 비교합니다. 변수 중요도는 평가자료의 열을 섞었을 때 예측 오차가 증가하는 정도입니다. 인과적 영향이나 통계적 유의성으로 해석하지 않습니다.

분류 유형은 매출 변화와 순진입률이 각각 0 이상인지에 따른 네 조합입니다. 이 기준은 분석 전에 고정한 기술적 구분이며, 지역사회 리질리언스의 성공·실패 등급이 아닙니다. 유형별 정밀도와 재현율을 함께 확인합니다.

`07_adjusted_model.R`은 현재 조직 없음 시장에서 전년도 지원중 사례가 관찰되지 않아 조직 유무 × 지원중 상호작용을 추정하지 않습니다. 비교 가능한 사례가 확보된 뒤 제3장의 보조가설을 재검토해야 합니다.
