2026 머신러닝 연구모임

2026년 한국정책분석평가학회 하계 방법론 워크숍 머신러닝 세션 참가자를 대상으로 하는 연구모임 저장소입니다.

어떻게 돌아가나

참여자: papers/<아이디>/_master.qmd 작성 → 각자 렌더 → _master.html 커밋
   ↓
Actions: HTML을 모아 대시보드 docs/ 생성 (Quarto·R 실행 없음)
   ↓
Cloudflare Pages 배포 → Access로 참여자 이메일만 허용

원자료는 각자 컴퓨터에 남고, 코드는 작성자 외에는 아무도 실행하지 않습니다.

참여자에게

  1. GitHub Desktop에서 Pull
  2. papers/내아이디/_master.qmd 수정
  3. quarto render papers/내아이디/_master.qmd
  4. _master.qmd 와 _master.html 을 함께 Commit → Push

자세한 안내는 배포된 대시보드 첫 페이지에 있습니다.

폴더 구조

papers/<아이디>/
├── _master.qmd      원고 겸 분석 문서 (각자 작성)
├── _master.html     렌더 결과 (커밋 필수, 대시보드가 이걸 가져감)
├── references.bib   참고문헌
├── data/            원자료 (저장소에 올라가지 않음)
└── outputs/         공개해도 되는 표·그림
scripts/build_site.py  대시보드 생성 (파이썬 표준 라이브러리만 사용)
theme-light.scss       원고가 참조하는 공통 테마
styles.css

설계 메모

저장소 루트에 _quarto.yml 을 두지 않습니다. 루트에 프로젝트 설정이 있으면 참여자가 자기 _master.qmd 하나만 렌더해도 Quarto가 프로젝트 전체를 해석하면서 다른 파일 때문에 실패할 수 있기 때문입니다. 대시보드는 Quarto 대신 scripts/build_site.py 가 HTML로 직접 만듭니다.

코멘트 기능(Hypothesis)은 빌드 시 각 HTML에 자동으로 주입되므로 _master.qmd 에 따로 설정하지 않아도 됩니다.

운영자에게

  • 참여자 추가: papers/<아이디>/ 폴더를 만들고 _master.qmd 를 복사해 넣으면 끝입니다.
  • 참여자 제외: 폴더를 지우면 표에서도 사라집니다.
  • _master.html 이 없는 폴더는 자동으로 건너뛰고 ‘준비 중’ 으로 표시됩니다.
  • 대시보드 문구·스타일 수정: scripts/build_site.py 상단의 SITE_TITLE, CSS, GUIDE
  • 필요한 시크릿: CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID
  • 접근 제한: Cloudflare Zero Trust → Access에서 참여자 이메일만 허용
